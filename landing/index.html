What it does

An assistant that actually uses your phone

Most assistants answer questions. AgentTool presses the buttons: dialing, typing, tapping and checking the result on a real device.

📞

Calls & messages

“Mom ko call karo”, “send SMS to Alice saying I'm late”. It finds the contact, confirms, then dials or sends over the phone's own apps.

💬

Controlled from WhatsApp

Text or voice-note the bot from anywhere. Voice notes are transcribed, you tap ✅ Yes / ❌ No to confirm, and the result comes back in the chat.

📱

Real screen control

Reads Android's accessibility tree and taps exact elements over ADB or the agent app: Calculator, YouTube, alarms, settings, Chrome.

🧠

Local Gemma

Intent understanding runs on the laptop with Gemma via Ollama. Commands and contacts stay on your machine; no LLM cloud key needed.

🗣️

Speaks your language

English, Hindi, Hinglish and Spanish, including follow-ups like “usko wohi message bhejo” or “call him instead”.

🛒

Shopping helper

“Buy a pen”: searches Flipkart, compares the real prices (cheapest and best value per piece) and opens the top pick. It never taps Buy or pays: that always stays with you.

How it works

From a sentence to a tap

No vision model: the agent reads the phone's accessibility tree, so taps land on the exact element every time.

1

You ask

Voice, web, or WhatsApp (signature-verified webhook).

2

Gemma understands

Local intent extraction: action, recipient, message, language.

3

You confirm

Calls and messages wait for “yes” or a ✅ tap, and expire after 2 minutes.

4

Phone acts

ADB / accessibility: open apps, type, tap Send or Call.

5

Honest result

Reports sent, not confirmed or failed, never a fake “done”.

Safety first

Powerful, but never reckless

An agent that can dial and message needs guard rails. These are built in and covered by an offline test suite.

  • ✓
    Confirmation before every call or messageRefusals like “mat karo” and corrections like “actually call Mom instead” never fire the old action.
  • ✓
    Locked-down APIOnly this laptop and the USB phone are trusted; Wi-Fi clients need a token; other websites and DNS rebinding are blocked.
  • ✓
    WhatsApp allowlistsOnly approved numbers can command the bot, and WhatsApp commands can only call or message approved numbers.
  • ✓
    Safe phone commandsMessage text is passed as quoted arguments, so it can't run commands on the device.
  • ✓
    Never buys or paysThe agent can't tap Buy, Place order or Pay buttons; it finds and opens the product, and you decide.

Get started

One command

Sets up Python, MongoDB (Docker) and the Gemma model, connects the USB phone, then starts the server.

# start everything (add the Android app with: make phone)
$ make dev
# control it from WhatsApp too (opens a secure tunnel for the webhook)
$ make dev WHATSAPP=1
# offline test suite: never touches a phone, the model or the network
$ make test
